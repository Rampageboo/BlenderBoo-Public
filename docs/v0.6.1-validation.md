The historical Smart UV failure reproduced before the fix. Blender 5.2
replaced the cached UV layer RNA reference when leaving Edit mode; the tool
now reacquires it. The closed cube rerun found 24 mesh loops, 24 UV items,
zero zero-area UV faces, and restored Object mode/selection. A separate
headless test exposed invalid BMesh edge handles after creating edge layers;
`mark_edges` now reacquires the edges. Its seam, sharp, crease, and bevel
weight assertions pass.

The direct add-on dispatcher does not pass through the MCP adapter and cannot
produce an MCP call-log record. The isolated adapter runner covers a real
bridge-routed call and a workflow child instead. It verified six records and
parent linkage. The normal installed desktop client was not restarted for
this validation. No asset modeling or GUI/hardware acceptance was performed.

Known typed-tool limits: UV overlap and cross-object texel density are not
measured; evaluated conversion does not force Geometry Nodes instance
realization; material curve-map points remain available through
`python.exec`. The 32-step workflow cap remains until call-log evidence
justifies changing it.
