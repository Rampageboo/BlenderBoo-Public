# v0.7.3 validation

## Scope and result

`api.lookup` reads the running Blender API without document mutation. Fragment
checks are bounded, informational review evidence. The add-on and MCP expose
matching 0.7.3 contracts.

## Focused evidence

| Check | Observed result |
| --- | --- |
| Fake RNA unit coverage | Struct, property, enum, function, operator, missing member, replacement, search, and paging cases passed. |
| Blender 5.2.2 API lookup | `Scene`, `Mesh`, `bpy.ops.mesh.bevel`, `bmesh.ops.bevel`, and `bmesh.ops.bevel` search succeeded. `Scene.node_tree` was absent; `Scene.compositing_node_group` was present and became the first suggestion through the official Blender 5.0 change-log entry, verified against live 5.2 RNA. |
| Lookup state and timing | A 10,003-object Blender scene retained its state token and dirty state across lookup calls. Mean summary lookup time was 0.107 ms, below one second. |
| Exec API failure | A `Scene.node_tree` AttributeError kept its original error and returned bounded `api_hint` evidence. |
| Fragment regression | A Boolean sliver produced `new_islands`; a clean modifier did not. `mesh.topology_report` supplied small-island focus. |
| Assembly regression | A detached screw appeared in `isolated_parts`, unless listed in `expect_isolated`; the focus and completeness flag were checked. |
| Large mesh connectivity | `component_summary` on 1.5 million sparse vertices completed in 0.293 s. This is a targeted connectivity cost, not a whole-scene exec budget. |

## Qualification boundaries

- Exec samples only mesh objects named literally in its code, capped in the
  receipt; dynamically selected targets have no pre-edit connectivity
  baseline. `diff:none` skips fragment sampling as well as snapshots.
- The typed post-apply checks cover `mesh.edit`, `modifier.apply`,
  `object.convert_evaluated`, `mesh.join`, and `mesh.separate`. Specialized
  builders that intentionally create separate meshes use their own
  task-specific validation.
- Island-count increases report small-island candidates, not a guaranteed
  identity match for each new component. They never cancel an edit.
- The curated API-change supplement has one verified entry:
  `Scene.node_tree` to `Scene.compositing_node_group`, sourced from the
  [Blender 5.0 Python API change log](https://docs.blender.org/api/5.0/change_log.html#bpy-types-scene)
  and checked against the [Blender 5.2 Scene API](https://docs.blender.org/api/5.2/bpy.types.Scene.html).
- A change in the real-world `python.exec` error-type mix needs later
  modeling-session call logs; it is observational and not this release's
  acceptance gate.
